# Pabliki Intelligence

Боевой тестовый интерфейс аналитики Instagram-пабликов: оценка качества, прогноз рекламных просмотров, подборки для клиентов, экспорт PDF и быстрая проверка пабликов.

> Текущие встроенные аналитические значения являются демо-данными. Реальные источники Instagram/Meta и серверное хранилище подключаются отдельным backend-этапом.

## Структура
- `index.html` — интерфейс
- `styles.css` — стили
- `app.js` — логика интерфейса и демо-аналитики
