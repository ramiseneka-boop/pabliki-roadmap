# Pabliki Intelligence

Боевой тестовый интерфейс аналитики Instagram-пабликов: оценка качества, прогноз рекламных просмотров, подборки для клиентов, экспорт PDF и быстрая проверка пабликов.

## Production test

- Vercel alias: `https://pabliki-intelligence-ramiseneka-boops-projects.vercel.app`
- Production deployment: `https://pabliki-intelligence-181y9a0me-ramiseneka-boops-projects.vercel.app`

> Текущие встроенные аналитические значения являются демо-данными. Реальные источники Instagram/Meta, постоянная база и история размещений подключаются отдельным backend-этапом.

## Структура
- `index.html` — интерфейс
- `styles.css` — стили
- `app.js` — ядро интерфейса и демо-аналитики
- `app-ui.js` — PDF, проверка пабликов, карточки анализа и обработчики интерфейса
